Get a source's queryable surface before writing a query: `dimensions` (its columns — scalars, records, and arrays), `measures`, `views` (each with its description and its Malloy code), and `joins` — the hierarchy of join paths it reaches (keyed by path; `fans_out` flags paths that multiply rows; the source's own joins show their join statement). To see the fields behind a join, call again with `path` set to that key (e.g. `principals.people`): it returns the fields at that path as a query through this source sees them. `source` is required; `model_ref` is optional when the source name is unique across the catalog.
